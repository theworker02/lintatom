# lintatom

Lint encode/decode helpers for atom payloads in pipelines.

**Site:** https://theworker02.github.io/lintatom/

## Install / run

```bash
git clone https://github.com/theworker02/lintatom.git
cd lintatom
node src/cli.js
node --test
```
